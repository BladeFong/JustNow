# 安排功能重设计

> 设计日期 2026-06-04

## 概述

重构任务安排功能：砍掉 MONTHLY 类型，安排关联时段组，时段组不生效时安排暂停，时间线去时段最大集。

## 安排类型选择器

### 顶层 RadioGroup → 动态列表

| 选项 | 出现条件 | 二级选择 |
|------|---------|---------|
| 单次 | 始终 | — |
| 工作日 | 工作日时段组已开启 | 每天 / 每周 |
| 春节 | 春节时段组已开启 | 每天 / 单次 |
| 暑假 | 暑假时段组已开启 | 每天 / 单次 |
| 寒假 | 寒假时段组已开启 | 每天 / 单次 |
| 长假 | 长假时段组已开启 | 每天 / 单次 |

顶层"单次"：选任意日期，系统调用已有时段组命中算法确定当天命中的时段组。

### 二级选择（时段组被选中时显示）

每行为两栏布局，始终全部可见，未选中栏置灰不可交互。

两栏间互斥：选中一栏自动取消另一栏。

- **工作日**：`[每天]` | `[一] [二] [三] [四] [五]`（或含 `[六]`，取决于时段组设置）
- **寒假/暑假/春节/长假**：`[每天]` | `[单次: yyyy-MM-dd]`

#### 交互规则

- 方块 `[每天]` 和 chip `[一]~[六]` 均为 toggle，选中态使用现有样式（蓝色实底白字）
- 日期选择器选中日期后，`[单次: yyyy-MM-dd]` 显示同样的选中态（蓝色实底白字），点击弹出 DatePickerDialog
- 两栏均不默认选中，用户必须选择其一才能保存
- 二级选择未选时保存按钮禁用

#### 周 chip 数量

工作日时段组的设置中新增模式选项：
- 标准（周一~五）：5 chip
- 6 天（周一~六）：6 chip

安排页根据该设置动态渲染 chip 数量。

#### 长假时段组的"单次"

日期选择器限定在该时段组的起止日期范围内，不允许超出。

## 槽位视图

槽位来源改为命中时段组的时段（当前实现取"今天"的时段）。

- 顶层"单次"：以所选日期命中时段组的时段为准
- 工作日时段组：以工作日时段组的时段为准
- 长假类时段组：以该时段组的时段为准

## 时段组关闭 → 安排失效

- 安排保存时记录关联的时段组（顶层"单次"不记录固定时段组，每次匹配）
- 时段组关闭后，关联安排当天不触发（调用已有命中接口判断）
- 时段组重新开启后安排恢复生效
- 顶层"单次"不受影响（每次自动匹配当天命中的时段组）

## 砍掉 MONTHLY

- TaskScheduleFragment 移除 `rb_schedule_monthly`
- MonthlyDayPickerDialog 删除
- TaskScheduleMatcher 移除 TYPE_MONTHLY 分支
- TaskScheduleEntity.TYPE_MONTHLY 常量删除
- DB schedule 表中已有的 MONTHLY 记录做迁移清理

## 时间线去时段最大集

主界面左侧时间线只显示当前生效时段组，不再合并所有时段组取最大集。

改动范围：TimelineBuilder 去掉 max-set 逻辑，改为使用当前生效时段组。

## 数据模型变更

### TaskScheduleEntity

| 变更 | 说明 |
|------|------|
| 删除 `TYPE_MONTHLY(3)` | MONTHLY 不再支持 |
| 新增字段 | 暂不确定是否需要新增字段记录关联时段组，实现阶段评估 |

### 安排-时段组关联

- 除顶层"单次"外，安排必须知道关联了哪个时段组
- 实现阶段评估：利用现有字段还是新增 `linkedPeriodGroupType` 字段

## 6 天工作制与周六的安排行为

- 6 天模式下安排到周六的任务，周六正常触发
- 周六同时落在长假类时段组范围内时，命中算法优先选长假类（详见 [时段组命中算法文档](2026-06-04-period-group-rule-update.md)），工作日安排当天不触发
- 切换 5/6 天模式后，已有一周安排的 chip 对应需重新评估：6 天→5 天时周六 chip 在安排列表中消失，关联安排保留记录但不再触发；5 天→6 天时已有安排不受影响（周六没有安排记录）

## 边界情况

| 场景 | 处理 |
|------|------|
| 所有时段组关闭 | 顶层"单次"仍可用；其他时段组选项隐藏 |
| 时段组关闭后再开启 | 关联安排自动恢复生效 |
| 工作日切 5/6 天后 | 已有每周安排的 chip 对应需重新评估 |
| 长假过期的安排 | 到期的长假时段组不再出现，关联安排自然失效 |
| 顶层"单次"命中时段组如果关闭 | 当天不触发 |
